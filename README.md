# تطبيق خطب الجمعة

يضم هذا المستودع تطبيق خطب الجمعة مع النصوص الكاملة، الفهرس، البحث الذكي، مواضع القراءة، و45 ملفًا صوتيًا مرتبة داخل مجلد `audio`.

يفتح التطبيق من ملف `index.html`. تم تضمين الخطوط والأيقونات محليًا داخل `pwa-assets`، ويحتوي المشروع على `manifest.webmanifest` و`sw.js` لدعم التثبيت والتخزين المحلي.
