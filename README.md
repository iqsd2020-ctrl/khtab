# مشروع خطب الجمعة — نسخة بدون ملفات صوتية

هذه نسخة كاملة من ملفات التطبيق باستثناء ملفات MP3. يحتوي `index.html` على النصوص والبحث الذكي والفهرس ومواضع القراءة والمشغل، بينما تشير روابط الصوت إلى ملفات GitHub المباشرة في مستودع `iqsd2020-ctrl/khtab`.

لتشغيل المشروع محليًا، افتح `index.html` عبر خادم محلي مثل `python3 -m http.server`، أو افتحه مباشرةً في المتصفح. سيعمل الصوت عند توفر الإنترنت لأن روابطه خارجية من GitHub، ولا توجد ملفات صوتية داخل هذا الأرشيف.

يتضمن المشروع `manifest.webmanifest` و`sw.js` وملفات الخطوط والأيقونات المحلية لدعم PWA.
